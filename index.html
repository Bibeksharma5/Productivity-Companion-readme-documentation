1. Introduction

Welcome to Productivity Companion — an all-in-one desktop application that brings a useful collection of everyday productivity tools together in a single, simple window. Whether you want to read an e-book aloud, convert a video to audio, generate an image with AI, check the weather, or organize your notes, Productivity Companion has a tool for it.

The application is built with accessibility as a first-class feature. It works smoothly with keyboard navigation and popular Windows screen readers such as NVDA, JAWS, and Narrator. Controls are clearly labelled, dialogs announce their results, and every feature can be reached without a mouse.

What can you do with it?

  • Read and analyze documents — PDF, EPUB, Word (DOCX), and PowerPoint (PPTX) files with a full-featured accessible reader.
  • Work with AI — chat with an AI assistant, generate images from text, and get spoken descriptions of pictures.
  • Convert almost anything — audio, video, images, documents, formats of every kind.
  • Create audio — convert text to speech, transcribe recordings, record your voice, and edit audio or video files.
  • Stay organized — manage notes and web links in categories, convert currencies, and check the weather.
  • Know your computer — view detailed information about your device's hardware and software.

Internet vs. offline

Some tools need an internet connection (they are marked with an Online badge in this guide), while others work fully offline (Offline). Several online tools can be made to work offline by downloading small language models in advance — see Tips & troubleshooting.

2. Getting started

Installation

Productivity Companion is distributed through the Microsoft Store:

  1. Open the Microsoft Store on your Windows PC.
  2. Search for Productivity Companion.
  3. Select the app and click Get (or Install) to download and install it.
  4. Launch Productivity Companion from the Start menu, the desktop shortcut (if you chose to create one), or directly from the Store.

Your first launch

When the application opens for the first time, a Welcome dialog greets you. It introduces the app and offers two buttons:

  • What's new — opens the release notes for the current version.
  • Got it — closes the dialog and takes you to the home screen.

If you do not want to see this dialog every time you start the app, tick the Don't show this dialog again checkbox before closing it.

Note On startup, the app may quietly check whether a newer version is available. If an update exists, you will be told to install it from the Microsoft Store. You can turn this automatic check off in Settings → General.

3. The home screen

The home screen is the heart of the application. It shows a list of every tool. The label above the list explains the most important interaction:

"Select feature and press enter to open (right click to see more options)"

Opening a feature

  1. Use the Up and Down arrow keys (or scroll with the mouse) to highlight a tool in the list.
  2. Press Enter, or double-click with the mouse, to open it.

When a feature window opens, the home screen hides. Use the Back button (present in every feature window) or press Alt+F4 to return to the home screen.

Reordering features

You can arrange the tools in any order you like, so your most-used tools are at the top:

  1. Highlight a tool in the list.
  2. Press the Application key (the menu key on your keyboard), press Shift+F10, or right-click with the mouse to open the context menu.
  3. Choose one of:
    • Open feature — open the selected tool.
    • Move up / Move down — nudge the tool one position.
    • Move top / Move bottom — jump the tool to the very top or bottom of the list.

Your custom order is remembered between sessions. To go back to alphabetical order at any time, press the Reset features order button.

Home screen buttons

Below the list you will find the following buttons. The underlined letter in each button label is its access key — hold Alt and press that letter to activate the button directly from anywhere on the home screen.

Reset features order (Alt+R)

Sorts the feature list back into alphabetical order.

Help (Alt+H)

Opens this user guide in your web browser.

What's new (Alt+N)

Shows the release notes for the current version.

Settings (Alt+I)

Opens the settings dialog — see the next section.

About (Alt+A)

Shows the app version and developer information, and links to the project's Telegram channel.

Check for update (Alt+U)

Manually checks whether a newer version is available.

Send feedback (Alt+K)

Opens the feedback form to send suggestions or report issues to the developers.

Exit (Alt+E)

Closes the application.

Tip Press Tab and Shift+Tab to move between the feature list and the buttons, Enter or Space to activate anything, and the Application key for context menus. Screen readers announce the selected feature and every button as you move through them.

4. Settings

Open Settings from the home screen to customize how Productivity Companion looks and behaves. The settings dialog is organized into tabs. Press Ctrl+Tab to move between tabs (or click them with the mouse). When you are done, press OK to save your changes or Cancel to discard them.

General

  • Application theme — choose Light, Dark, or System default (the app follows your Windows appearance setting).
  • Program display language — choose English, नेपाली (Nepali), or Türkçe (Turkish). Changing the language asks you to restart the app so the new language takes effect.
  • Automatically check for updates on startup — tick this to be notified of new versions when the app opens.

Document reader

Default settings applied when you open the Document Reader:

  • Zoom — default zoom percentage (10–500%).
  • Font size — default reading font size.
  • High contrast and Invert colors — display options for easier reading.
  • Auto-scroll speed — speed of automatic scrolling (0 = slow, 9 = fast).
  • Extraction profile — how text is pulled out of documents (default, simple, detailed, ocr_only, clean).
  • Default export directory — where exported files are saved.
  • Enable TTS chunking — splits long texts into smaller chunks for more reliable speech generation.

Text to speech

  • Engine — Google text to speech (choose a default language) or Microsoft Edge voices (natural neural voices).
  • Voice — for Edge voices, pick a voice (for example en-US-AriaNeural). Click Fetch latest voices to refresh the list of available voices from the server.
  • Speed, pitch, and volume — fine adjustments for Edge voice output.

These settings are shared by the Text To Speech converter and the Document Reader's Read Aloud feature.

Audio transcription

  • Transcription mode — Online (fast, cloud-based, no setup) or Offline (private, runs entirely on your PC).
  • Whisper model — for offline mode, download a free Whisper speech-recognition model. Smaller models (tiny, base) are quick to download and fast, while larger models (medium, large-v3) are slower but much more accurate. Download once — after that, transcription works with no internet.
Tip Choose a model that matches your needs. The base model is a good balance of speed and accuracy; use large-v3-turbo when accuracy matters more and your computer can handle it.

Recorder

  • Default recording path — the folder where new recordings are saved (choose one with Browse Recording Path).
  • Channel — Mono (1) or Stereo (2).
  • Sampling rate — 44100 or 48000 Hz (higher is better quality).
  • Record as — WAV (uncompressed) or MP3 (compressed, smaller files).

Conversion

Manages Pandoc, the conversion engine used by the Word to EPUB, HTML to Markdown, and Markdown to HTML tools. If Pandoc is not installed, click Download Pandoc. If you no longer need it, the button changes to Remove Pandoc.

OCR

Manages Tesseract OCR, the engine used by the Image OCR tool and the Document Reader's OCR features:

  • Download / Remove Tesseract OCR — install or uninstall the OCR engine.
  • Download additional languages for OCR — choose from a large list of languages (the list is read live from the Tesseract repository). Each language can be downloaded as a Fast model (smaller, quicker) or a Best model (higher quality). Installed languages can also be removed from this dialog.

More

  • Clear productivity companion cache — deletes saved settings, cached voices, downloaded transcription models, temporary files, and your custom feature order. Use this if the app misbehaves or you want a fresh start.
Warning Clearing the cache removes downloaded Whisper models and OCR language data — you would need to download them again afterwards. Your notes and saved links are stored separately and are not removed.

6. AI & knowledge tools

6.1 AI Assistant Online

A conversational AI assistant built into the app. Ask questions, request summaries, get writing help, or analyze a document or image that you attach from another tool. Responses are shown in a readable format, and your conversation history is kept while the window is open.

How to use it

  1. Open AI Assistant from the home screen.
  2. Optionally tick Web search to let the assistant search the internet for up-to-date answers, or Thinking for deeper, step-by-step reasoning. (The two options switch each other off.)
  3. Type your prompt in the text field and press Enter or press the Send button. The button changes to Stop response — press it if you want to stop the reply early.
  4. Attach content — the assistant itself does not have a file picker; instead, documents and images are attached from other tools and arrive here pre-loaded:
    • From the Document Reader, press Ask AI assistant (see section 7.1) to open the assistant with your opened PDF, EPUB, DOCX, or PPTX attached, ready for questions, analysis, or summaries.
    • From the Image Describer, supply an image (file, camera, or clipboard) and the assistant opens with that picture attached and a description request pre-filled.
  5. Navigate through the conversation list with the arrow keys. Use the context menu (right-click or Application key) on any message to:
    • Open — view the message in its own window.
    • View formatted — see the rendered (formatted) version.
    • Copy — copy the message text to the clipboard.
    • Save as — save it as a Markdown (.md) or text (.txt) file.
    • Translate — send the text to the Text Translator.
    • Generate audio — send the text to the Text To Speech converter.
    • View thoughts — if you used the Thinking option, see the assistant's reasoning.
Note The AI Assistant needs an internet connection. A short typing sound plays while the assistant is generating a response.

6.2 Wikipedia Search Online

Search Wikipedia and read summaries of articles without leaving the app.

  1. Open Wikipedia Search.
  2. Type a search term in the Search term field and press Enter or the Search button.
  3. Browse the list of matching article titles.
  4. Select an article and press Enter (or use the context menu) to read its summary, or open the full article in your default web browser.

6.3 Text Translator Online

Translate text between a wide range of languages using an online translation service.

  1. Open Text Translator.
  2. Type your text, or load a .txt file with the Load button.
  3. Choose the target language (the source language is detected automatically).
  4. Press Translate. The button changes to "Translating, click to cancel" — press it again at any time to cancel.
  5. Read the result, and use Copy to put it on the clipboard.

You can also reach this tool from other features: for example, an AI Assistant response or a transcription can be sent straight to the translator.

7. Reading & document tools

7.1 Document Reader Offline*

The most feature-rich tool in the app. Read PDF, EPUB, Word (DOCX), and PowerPoint (PPTX) documents with a workspace designed for keyboard users and screen readers, and work with the documents using a wide range of built-in tools.

Opening a document

  1. Open Document Reader.
  2. Press Import document (or Ctrl+I from the File menu) and choose a PDF, EPUB, DOCX, or PPTX file.
  3. If the file is a password-protected PDF, enter its password when prompted.

The document is divided into sections (pages, chapters, or slides). The toolbar tells you which section you are on (for example "Section 5 of 120"). Use Alt+PageDown for the next section and Alt+PageUp for the previous one.

Reading comfortably

  • Reading modes — switch between Plain Text (best for screen readers) and Formatted (preserves layout) using the Mode drop-down.
  • Zoom — Ctrl++ to zoom in, Ctrl+- to zoom out, Ctrl+0 to reset.
  • High contrast — Ctrl+H.
  • Invert colors — Ctrl+Shift+I.
  • Dark mode — from the View menu.
  • Split view — Ctrl+Shift+V to read two sections side by side.
  • Auto-scroll — start automatic scrolling; adjust its speed in Settings → Document reader.

Finding and copying text

  • Find — Ctrl+F; jump between matches with F3 and Shift+F3.
  • Find and replace — from the Edit menu.
  • Copy section text — Ctrl+C; Copy all text — Ctrl+Shift+C.
  • Export — Ctrl+Shift+E to save the document as text, DOCX, audio book, CSV, JSON, or HTML.

Working with AI

  • Ask AI assistant — the Ask AI assistant button (Alt+K) opens the AI Assistant with your currently opened document already attached. You can then ask questions about its contents, request an analysis, or have the whole document summarized in refined, well-written language. Works with PDF, EPUB, DOCX, and PPTX files.
  • Deep inside with AI — the Deep inside with AI button (Alt+I, PDF files only) turns the current page into a highly accessible presentation. The page is analyzed by AI and rebuilt as a clean, screen-reader-friendly document in which:
    • All text is extracted with its original wording preserved.
    • Every mathematical equation, formula, fraction, and symbol is written in MathML, so equations are read correctly by screen readers instead of being announced as gibberish.
    • Tables and charts are re-presented as accessible tabular data, and every image receives a natural, informative alt text description.
    • The result opens in its own resizable window with Previous Page / Next Page navigation, a Go to page box, and a Reanalyze button for fresh results.
    This makes it especially valuable for blind and visually impaired readers working with PDFs that contain mathematics, tables, charts, or graphs. Results are cached, so revisiting a page does not repeat the analysis.
  • Open in web viewer — the Open in web viewer button (Alt+W) is available for EPUB and PPTX files. It opens the document in a formatted web view — a smart reading experience with the original layout, styling, and structure, ideal for e-books and presentations.
Note Ask AI assistant and Deep inside with AI need an internet connection. Deep Inside is only offered for PDF files, and the Web viewer only for EPUB and PPTX files.

Listening and translating

  • Read Aloud — Ctrl+R reads the current section with your configured TTS voice. You can pause, resume, restart, adjust speed and volume, and save the speech to an audio file.
  • Voice Preview — preview the chosen voice before reading a full section.
  • Translate Section — Ctrl+Shift+T translates the current section online.

OCR for scanned or image-based pages

  • OCR — Ctrl+Shift+O recognizes text on the current page using Tesseract (download it from Settings → OCR if asked).
  • Text extraction profiles — Ctrl+Shift+P to choose how text is extracted (default, simple, detailed, ocr_only, clean).
  • Recognized text is cached, so you rarely need to OCR the same page twice. Clear the cache for the current page, the whole document, or everything from the Tools menu.

Studying and analyzing

  • Bookmarks — Ctrl+B to bookmark the current section; Ctrl+Shift+B opens the bookmarks manager; bookmarks can be exported to a JSON file.
  • Table of contents — Ctrl+T.
  • Annotations & highlights — add notes to a section (Ctrl+Shift+N) or highlight selected text (Ctrl+Shift+L); manage them with Ctrl+Shift+H.
  • Compare sections — Ctrl+Shift+C compares two sections.
  • Statistics — Ctrl+Shift+S shows reading statistics.
  • Extract links — collects all web links found in the document.

Editing and manipulating PDFs

Warning These tools change the PDF file itself. Always work on a copy of an important document, and keep your original safe.
  • Protect PDF — add a password; Unlock PDF — remove or enter a password.
  • Redact text — permanently hide sensitive words (they are replaced by blank space).
  • Rotate page — clockwise or counter-clockwise.
  • Delete section, Extract sections, and Split PDF — reorganize the file into smaller pieces.
  • Add watermark — stamp text onto pages.
  • Extract images from PDF and Save page as image — pull graphics out of the document.

Document library

On the reader's start screen you can also open the Document library — a list of documents you have previously added, so you can reopen them quickly.

Document properties — Ctrl+M shows file details such as title, author, and page count.

7.2 Image OCR Offline†

Recognize and extract text from pictures (.jpg or .png) using the Tesseract OCR engine.

  1. Open Image OCR. The first time, you may be asked to download Tesseract OCR — press Yes and wait for the download to finish (you can also manage it later in Settings → OCR).
  2. Press Open file and choose an image.
  3. Choose the primary language for recognition. Tick the checkbox to also set a secondary language (useful for mixed-language images).
  4. Press Start. The recognized text appears in the result box.
  5. From the result you can save it as a text file, copy it, translate it, or convert it to audio.
Tip If a language is not installed, the app tells you exactly where to download it: Settings → OCR → Download additional languages for OCR.

7.3 PDF to Image Offline

Export every page of a PDF as a separate PNG image.

  1. Open PDF to Image and choose a .pdf file.
  2. Press Export to images and pick the destination folder.
  3. The app renders each page at 300 DPI and saves them as page_1.png, page_2.png, and so on.

7.4 Image to PDF Offline

Combine several images into a single PDF document.

  1. Open Image to PDF.
  2. Add your images to the list.
  3. Re-arrange the order with the context menu (Move up / down / top / bottom, Remove image) so the pages come out in the right sequence.
  4. Press the export button, choose a filename, and save the PDF.

7.5 Word to EPub Offline†

Convert Microsoft Word documents (.docx) into EPUB e-book files.

  1. Open Word to EPub. If Pandoc is not installed, the app offers to download it (or use Settings → Conversion).
  2. Press Open word document and choose a .docx file.
  3. Press Save to epub document and choose where to save the .epub output.

7.6 HTML to Markdown Offline†

Convert web-page files (.html) into Markdown (.md) — handy for taking notes or publishing content.

  1. Open HTML to Markdown (Pandoc is required; download it if prompted).
  2. Press Open HTML document and choose an .html file.
  3. Press Save to markdown file and choose the output location.

7.7 Markdown to HTML Offline†

Do the reverse: convert Markdown files (.md) into HTML documents.

  1. Open Markdown to HTML (Pandoc is required).
  2. Press Open Markdown file and choose an .md file.
  3. Press Save to HTML document and choose the output location.

8. Audio & video tools

8.1 Text To Speech Online

Turn written text into spoken audio files (.mp3) with natural voices.

  1. Open Text To Speech.
  2. Type your text, or load a .txt file with the Load button.
  3. Check the Voice button — it shows the current engine and voice. Press it to switch between Google text to speech (pick a language) and Microsoft Edge voices (pick a natural voice; speed, pitch, and volume come from Settings → Text to speech).
  4. Press Generate, choose where to save the .mp3, and wait for the conversion. The button changes to "Generating, click to cancel" — press it again to cancel.
  5. When finished, press Play to hear the result inside the app.
Tip Microsoft Edge voices sound very natural and let you adjust speed, pitch, and volume. Use Fetch latest voices in Settings to see the newest voices available.

8.2 Audio Transcriber Online / Offline

Convert speech in audio files (.mp3, .wav, .flac, .ogg, .m4a) into readable text.

  1. Open Audio Transcriber.
  2. Choose your mode in Settings → Audio transcription:
    • Online — cloud-based AI transcription. Fast and accurate; needs internet. No setup required.
    • Offline — runs on your PC with a Whisper model. Download a model first in Settings → Audio transcription (models range from tiny to large-v3).
  3. Press Select audio file to transcribe and choose your file.
  4. Transcription begins and progress is shown. The button becomes Cancel — press it to stop.
  5. When it finishes, you can copy the transcript, translate it, or convert it to audio.
Note The transcriber keeps the original language of the audio and notes when the speaker changes (a [speaker changed] marker is added at the start of a new line).

8.3 Voice Recorder Offline

Record voice memos and audio notes directly with your microphone.

  1. Open Voice Recorder.
  2. Choose where to save the recording with the Browse button (the default folder comes from Settings → Recorder).
  3. Press Start recording (the button changes to Stop recording).
  4. Use Pause/Resume if you need a break mid-recording.
  5. Press Stop recording to finish and save the file as WAV or MP3 (the format is chosen in Settings → Recorder, along with mono/stereo and sampling rate).
  6. Press Play to listen back inside the app.

8.4 Video to Audio Offline

Extract the audio track from a video so you can listen to it anywhere.

  1. Open Video to Audio.
  2. Press Open Video file and choose a video.
  3. Choose the output format: mp3, wav, or m4a.
  4. Optionally tick Enable high quality conversion (slower but better quality).
  5. Press Save to audio and choose where to save the result.

Batch conversion: tick Enable multiple video conversion to import up to 10 videos at once, then convert them all in one go.

8.5 Audio to Video Offline

Turn an audio file into a video — useful for uploading music or podcasts to video platforms.

  1. Open Audio to Video.
  2. Press Open audio file and choose your audio (.mp3, .wav, .m4a, .flac, .aac, .ogg, .wma).
  3. Optionally press Add Image to Video to use a picture as the video's visual (otherwise a default background is used).
  4. Choose the aspect ratio: 16:9 (landscape) or 9:16 (vertical, for shorts/reels).
  5. Optionally tick Enable high quality conversion.
  6. Press Convert and save the result as .mp4 or .mkv.

8.6 Audio Video Editor Offline

A keyboard-accessible editor for audio and video files. Open a file, pick an action, and export the result. Supported formats include .mp3, .wav, .m4a, .aac, .flac, .ogg, .wma for audio and .mp4, .mkv, .avi, .mov, .flv, .wmv, .webm for video.

  1. Open Audio Video Editor (the first open takes a moment to initialize).
  2. Press Open audio or video file and choose your file. Its name appears in the status bar.
  3. Choose an action from the list:
    • Trim — keep only the part of the file between a start and end point.
    • Cut — remove a selected portion and join the remaining parts.
    • Split — divide the file at a chosen point into separate files.
    • Add background music — mix a music track under a video (videos only).
    • Add watermark — overlay text or an image on a video (videos only).
    • Change volume — boost or lower the volume of the whole file or a segment.
    • Change echo — add an echo effect.
    • Merge — combine your file with a second file, appending it to the beginning or the end.
  4. Set the options for the chosen action, then preview the result and export it to a new file.

8.7 Global Radio Player Online

Stream live radio stations from anywhere in the world by entering a streaming URL.

  1. Open Global Radio Player.
  2. Paste a live streaming URL into the field and press Play.
  3. Control playback with Play/Pause and Stop in the player window.
Tip The same built-in player is used by other tools — for example, the Voice Recorder and Text To Speech use it to play back your recordings and generated audio.

9. Image tools

9.1 Image Generator Online

Create images from a text description using an online AI image model.

  1. Open Image Generator.
  2. Describe what you want in the prompt field (for example: "a red fox sitting in a snowy forest at sunset").
  3. Press Generate Image and wait — generation can take a minute.
  4. The preview appears in the window. Press Save Image to export it (PNG, JPG, or BMP).
Note Generation needs an internet connection. If a request times out, try a shorter or simpler prompt.

9.2 Image Describer Online

Get a spoken or written description of an image — helpful for understanding pictures, checking layouts, or identifying objects.

  1. Open Image Describer.
  2. Choose how to supply the image:
    • Open Image — pick a file (.png, .jpg, .jpeg, .gif, .bmp, .webp, .tiff).
    • Take Picture — capture a photo with your webcam.
    • Describe from clipboard — paste a copied image or an image URL.
  3. Wait for the AI analysis; the description is shown in the result area.

9.3 Image Resizer Offline

Shrink large photos (.jpg, .jpeg, .png) down to roughly 30 KB so they are quick to send by email or messaging apps.

  1. Open Image Resizer.
  2. Press Open image and choose your picture.
  3. Press Resize and choose where to save the smaller .jpg.
  4. The app reduces the dimensions and compression until the file is small; if the image is already small enough, it tells you no resizing is needed.

9.4 Text to Image Offline

Design attractive text cards, banners, and posters by turning typed text into a finished image (up to 1000 characters).

  1. Open Text to Image.
  2. Type your text in the large edit field.
  3. Customize the design:
    • Font, font size, and text color (colors are chosen automatically for good contrast against your background).
    • Background style and colors, frame/border options.
    • Optional Logo / Watermark: tick Add logo or watermark, choose an image, and set its position (for example top-left or bottom-center), opacity, and size.
  4. Preview the result and export it as an image file.

9.5 Media Converter Offline

Convert one media format into another — image, audio, or video — using the bundled FFmpeg engine.

  1. Open Media Converter and choose Image Converter, Audio Converter, or Video Converter.
  2. Press Select image/audio/video and choose your file.
  3. Pick the output format:
    • Image: png, jpg, jpeg, bmp, gif, webp, tiff.
    • Audio: mp3, wav, aac, flac, ogg, m4a.
    • Video: mp4, avi, mkv, mov, webm, flv.
  4. Press Convert. The converted file is saved next to the original with the new extension.
Note The output format must be different from the input format. Large video conversions can take a while — a progress dialog keeps you informed.

10. Everyday utilities

10.1 Notes Manager Offline

Write and organize notes inside categories. Everything is stored locally on your computer in a notes.json file.

  1. Open Notes Manager.
  2. Create a category (for example "Work", "School", "Ideas") with the New category button.
  3. Add a note inside the category with the New note button — give it a title and content.
  4. Use the context menu to edit, delete, or rename categories and to manage notes.
  5. Use Export to back up all your notes to a JSON file, and Import to restore or move them to another computer.

10.2 Link Saver Offline

Keep your favorite web addresses organized in categories so you never lose a useful link.

  1. Open Link Saver.
  2. Create a category (for example "Articles", "Tools", "Social").
  3. Add a link with a title and URL. Use the context menu to edit, delete, copy, or rename categories.
  4. Press Enter (or choose Open from the context menu) on a saved link to open it in your default web browser.
  5. Use Export/Import to back up your links as a JSON file.

10.3 Currency Converter Online

Convert amounts between 40 world currencies using up-to-date exchange rates.

  1. Open Currency Converter.
  2. Choose the currency you are converting from.
  3. Choose the currency you are converting to.
  4. Enter the amount.
  5. Press Convert — the result appears in the read-only result box.
Note Rates come from a live online service, so an internet connection is required and the result is only as current as the latest rate update.

10.4 Weather Online

Get current weather conditions and a multi-day forecast for any city in the world.

  1. Open Weather.
  2. Type the name of a city (for example Kathmandu) in the field.
  3. Press Fetch weather info.
  4. Read the current conditions — temperature, feels-like temperature, humidity, wind speed and direction, pressure, visibility, cloud cover, UV index, and precipitation — followed by the daily forecast (maximum/minimum/average temperature, sunrise, and sunset).
  5. Press Copy weather info to copy the whole report to the clipboard.

10.5 Device Information Offline

See a complete overview of your computer: operating system, processor (including Intel and AMD generation detection), memory, storage partitions, graphics card, battery, BIOS, motherboard, boot mode, and Secure Boot status.

  1. Open Device Information.
  2. Wait a moment while the app gathers details about your system.
  3. Browse the categories in the list; activate any item to view its full value.
  4. Use the copy buttons to copy individual values (for example, your CPU name) to the clipboard.
Tip This is handy when you need to check system requirements, find your Windows version, or share your hardware details with support staff.

12. Accessibility

Productivity Companion is designed to be usable by everyone, including people who rely on screen readers, magnification, or keyboard-only navigation. Here is what you can expect:

  • Screen reader support — the app is built with wxPython and works well with NVDA, JAWS, and Windows Narrator. All buttons, lists, and dialogs have meaningful labels that are announced when you focus them.
  • Full keyboard access — every action can be performed with the keyboard. Lists respond to the arrow keys, Enter opens the selected feature, and Tab moves through buttons.
  • Access keys — buttons with underlined letters can be activated with Alt+letter, e.g. Alt+I for Settings.
  • Context menus — use the Application key (or Shift+F10) anywhere a right-click menu is available.
  • Announced state changes — checkboxes announce their state (for example "Web search (on)" / "Web search (off)"), and buttons change their labels to reflect what will happen next ("Stop recording", "Cancel", "Generating, click to cancel").
  • Visible focus — the focused control is clearly indicated, making it easy to follow along with or without a screen reader.
  • Themes — choose Light, Dark, or System default in Settings → General. High contrast and color inversion options inside the Document Reader help with low vision.
  • Speech everywhere — the Text To Speech tool and the Document Reader's Read Aloud can read content aloud, and transcribed or OCR'd text can be turned into audio files.
  • Multiple languages — the interface is available in English, Nepali, and Turkish, and TTS supports a very large set of languages.
Accessibility of this guide This guide itself is written with accessibility in mind: it uses semantic headings and landmarks, a skip link, keyboard-friendly navigation, high-contrast colors, and a dark mode that follows your system settings. The Help button in the app opens this page in your web browser.

13. Tips & troubleshooting

Internet requirements

These features need a live internet connection: AI Assistant, Image Generator, Image Describer, Wikipedia Search, Text Translator, Currency Converter, Weather, Global Radio Player, Text To Speech (both engines), online transcription, and update checks. If a feature reports a connection error, check your network and try again.

Working offline

  • Offline transcription — download a Whisper model once in Settings → Audio transcription, then switch the mode to Offline.
  • Offline OCR — download Tesseract and your languages in Settings → OCR, then use Image OCR or the Document Reader's OCR with no internet.
  • Offline document conversion — download Pandoc once in Settings → Conversion for Word to EPUB, HTML to Markdown, and Markdown to HTML.
  • Everything else marked offline — media conversion, image editing, notes, links, recording, device information — works without any connection.

Common questions

Common problems and their solutions
ProblemSolution
"Tesseract OCR is not downloaded" Answer Yes to download it, or open Settings → OCR → Download Tesseract OCR. Then add languages with Download additional languages for OCR.
"Pandoc is required" when converting documents Download Pandoc from Settings → Conversion (or accept the in-app prompt). It is used by Word to EPub, HTML to Markdown, and Markdown to HTML.
Offline transcription says no model is available Go to Settings → Audio transcription, pick a Whisper model and press Download. Wait for it to finish (large models take time), then transcribe again.
An OCR language is "not installed" Open Settings → OCR → Download additional languages for OCR, choose the language (Fast or Best model) and download it, then retry.
AI Assistant or online tools fail These require internet. Check your connection and try again; for the Image Generator, try a shorter prompt if a request times out.
The app behaves oddly or feels slow Open Settings → More → Clear productivity companion cache. Note this deletes settings, downloaded models, and your feature order (see the warning in the Settings section).
I want to undo my feature order changes Press Reset features order on the home screen to return to alphabetical order.
How do I update the app? Press Check for update (or let the automatic check run). If a new version exists, install it from the Microsoft Store.
Where is my data stored? Notes, links, settings, downloaded models, and caches live in the app's data folder: %LOCALAPPDATA%\Packages\BlindTechNexus.ProductivityCompanion_bpastbqzbm4dw\LocalState. Export notes and links to JSON regularly for safe backups.

Good habits

  • Before manipulating a PDF (redact, split, delete pages, watermark), work on a copy so the original stays intact.
  • Back up your Notes Manager and Link Saver data regularly with their Export buttons.
  • Large downloads (Whisper models, OCR languages, Tesseract, Pandoc) only need to happen once — after that they work offline.
  • Use the Send feedback button to report bugs or request features; the developers read every message.
